About The Project

Traditional voting methods in colleges and small organizations can create low participation, manual errors, duplicate voting, and delayed result declaration. This system provides a transparent browser-based alternative for small elections without PHP or backend setup.

All data is stored in browser Local Storage for academic demonstration. The implementation is intentionally beginner-friendly and divided into separate HTML, CSS, and JavaScript files.

Software Engineering Project Details

The Secure Online Voting System solves participation, manual counting, duplicate voting, and delayed result problems in small organization elections by providing a digital platform for voter registration, login, voting, candidate administration, and automatic results.

  • Secure voter authentication.
  • Allow only one vote per voter.
  • Provide easy candidate management.
  • Count votes automatically.
  • Display results with charts and winner declaration.

The system is suitable for college elections, club elections, class representative voting, and small organization polls. It demonstrates frontend-only voting logic using Local Storage and is not intended for government-scale production elections.

Voters: register, login, view candidates, and vote once. Administrator: manages candidates, voters, statistics, and reset operations. Candidates: present profile and manifesto to voters.

Home page, voter registration, voter login, candidate display, vote casting, vote once validation, admin login, add/delete candidates, view voters, statistics monitoring, reset election, automatic vote counting, winner declaration, and Chart.js bar chart.

Responsive design, fast performance, input validation, user-friendly interface, browser compatibility, and safer Local Storage handling through structured keys and session state.

A voter registers, logs in, views candidate profiles, casts one vote, and logs out. An administrator logs in, adds candidates, deletes candidates, views voters, monitors statistics, and can reset the election. The results page automatically reads vote data and declares the winner.

The browser UI layer is built with HTML, CSS, Bootstrap, and JavaScript. The application logic layer handles authentication, voting, admin actions, and chart results. The storage layer uses Local Storage for voters, candidates, sessions, and election status.

Email OTP verification, biometric authentication, blockchain-based voting, role-based access control, cloud database integration, audit logs, encrypted credentials, and printable election reports.

The Secure Online Voting System demonstrates how digital tools can improve small election transparency, speed, and usability. It satisfies core SPL requirements while remaining simple enough for beginner-level explanation and viva presentation.
